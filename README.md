# Snake Game

This repository contains a terminal-based Snake game implemented in Python using the `curses` module. The game keeps track of a high score between runs and can be controlled using the arrow keys.

## Running the Game

1. Ensure you have Python 3 installed.
2. Run the following command from the repository directory:

```bash
python3 snake.py
```

Press **q** at any time to quit. When the game ends, press **r** to restart or **q** to exit.

The high score is saved in `highscore.txt` in the repository directory.
